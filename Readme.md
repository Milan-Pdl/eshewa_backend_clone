# ESHEWA_BACKEND

A modular Python-based backend system designed with FastAPI and a clean architectural pattern.

## 🚀 Features
- **Modular Structure:** Separated routers, models, and utility functions for scalability.
- **Database Integration:** SQL-based data management using SQLAlchemy.
- **Authentication:** Secure user authentication logic.
- **Configurable:** Easy setup using environment variables.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** FastAPI / Pydantic
- **Database:** SQL (MySQL/PostgreSQL)
- **Tooling:** Git, SQLAlchemy
